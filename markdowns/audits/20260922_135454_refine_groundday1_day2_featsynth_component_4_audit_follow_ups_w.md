## 4. Architectural Weaknesses & Vulnerabilities Identified

**Carried over: still open, and conditions of this verdict**
- [ ] **C-1 (HIGH, interface):** `AnswerOutput` still has no fields for `retrieval_required`, `suppression_reason`, `claims`, `version_lineage` or `telemetry`. They travel in `SynthesisResult.extensions`. This is a team decision (schema v1.1, or an agreed rule that the harness logs `to_json()`).
- [ ] **C-2 (HIGH, interface):** the frozen `Claim` still has no `confidence`, `superseded_by` or `"retracted"`. `ClaimMeta` holds the first two. This is a team decision.
- [ ] **C-3 → harness adoption (MEDIUM, integration):**
  - The hook exists and a golden test replays Examples 1–3 in harness order (classify → skip upstream → `handle_turn`). The outputs are identical to the post-decomposition run, and Example 2's refinement turn issues only its 2 targeted queries.
  - `full_corpus_searches: 0` holds system-wide only once Matangi's harness calls `classify()` at `utterance_end` and honours `needs_upstream_retrieval`.

**New or residual weaknesses in this update**
- [ ] **N-1 (MEDIUM, hallucination): the polarity check is lexical.**
  - It catches explicit negation (`not`, `no`, `never`, `without`, `n't`, …) and parity flips.
  - It misses antonym inversions ("deposits are *forfeited*" vs "*refunded*", "*prohibited*" vs "*allowed*").
  - It can falsely retract "not only X but also Y" constructions, where the parity looks negative. That failure is conservative: a retracted sentence becomes uncertainty.
  - Alignment splits clauses on sentence boundaries, `;` and `:` only, so a negated "…, but not Y" clause inside one comma-separated sentence is judged together with the rest of the sentence.
  - The cross-encoder backend (I-4, baking the model) is still the real fix. The polarity check stays on as a cheap backstop for either backend.
- [ ] **N-2 (MEDIUM, latency): streaming granularity is one claim, not one token.**
  - Time to the first provisional sentence is the time to generate the first whole claim object (≈ 20–40 tokens), not the first token.
  - It only improves if the server streams schema-constrained output incrementally. vLLM guided decoding and Ollama structured outputs both do; a server that buffers constrained output would silently fall back to whole-response latency.
  - **Not yet measured against a live local Qwen2.5-7B.** `GenerationUsage.first_draft_ms` is now emitted in `synthesis.generation` telemetry, so this can be measured as soon as the model runs.
- [ ] **N-3 (LOW, concurrency): `classify()` and `handle_turn()` must run under the same `SessionStore.turn()` lock.**
  - This is documented but not enforced. If a turn interleaves between them, the precomputed classification could describe stale session state.
  - Pre-decomposition classification has no sub-intents, so presentation detection relies on the controller decision plus lexical anchors. The goldens are unaffected, but a turn with a novel facet and a presentation verb, where the controller did not flag NO_RETRIEVAL, depends on facet keywords alone.
- [ ] **N-4 (LOW, UX): the all-or-nothing restyle can look like an ignored request.**
  - One ungrounded sentence reverts the whole translation to the English prose render, while `suppression_reason` still reads `translation`.
  - Non-Latin digits in the output fail the copy check, again falling back conservatively.
  - The fallback reason is logged (`synthesis.render.restyle = fallback:<reason>`). A UI note ("translation unavailable, showing original") would make it visible.
- [ ] **N-5 (LOW, state): session expiry is swept lazily, on every store access.**
  - With no traffic at all, idle sessions linger until the next access, or until the harness calls `sweep()` on a timer.
  - `SessionStore.get()` outside `turn()` is not serialised.
  - A turn already queued on a session that is `end()`ed runs on the ended session, which is then destroyed, rather than on a fresh one.
- [ ] **N-6 (LOW, parsing): stray braces are counted as broken.**
  - `ClaimStreamParser` tracks strings only inside JSON objects, so a stray `{` in model prose before the JSON counts as one broken fragment.
  - The non-streaming parser behaves the same way, and 27 parity tests (9 output shapes × 3 chunk sizes) pin the two together.
  - For truncated output the streaming parser counts exactly one lost claim. The whole-text parser also counts the unclosed wrapper.

**Still open from the previous audit (unchanged by this update)**
- [ ] W-2 (CrossEncoder lock), W-5 (example-shaped slot lexicon and delta queries: re-derive from the corpus audit), W-6 (regex proper-noun heuristic), W-8 (mixed constraint and new-facet turns not split).

## 6. Architectural Strengths & Alignments
- [x] **G4 closes a real loophole.** "Card statements alone are accepted" used to commit at entailment 1.0 against a chunk saying they are *not* accepted. It is now retracted, and parametrised tests cover dropped negation, added negation, `never`, contractions (`aren't`), and re-attribution not rescuing a flipped sentence.
- [x] **HC-4 is now structural.** Expiry and destruction are owned by one store, not left to harness discipline. Per-session serialisation removes the `ClaimGraphError` concurrency hazard (W-3) by construction.
- [x] **G5 can hold system-wide.** Routing before decomposition makes "refinement never triggers a full upstream search" enforceable by the harness. The routed replay produces byte-identical outputs to the reference run.
- [x] **Presentation stays retrieval-free and grounded.** A restyle cannot add a label (`citations ⊆ prior` is still asserted in `render_presentation`), cannot invent a number or name (copy check), and cannot drop content (label coverage). The graph is never mutated.
- [x] **Two-pass streaming is real on the LLM path.** Verification of sentence N now overlaps generation of sentence N+1 in time, not just "verify while the next already-generated draft is consumed". An engine-level test shows the first PROVISIONAL event reaching the consumer before the server has sent the last content line.
- [x] **Everything is ablatable from config:** `verifier.polarity_check`, `presentation.llm_restyle_reasons: []`, `generator.openai_compatible.stream: false`, and `session.ttl_s`.
