## 4. Architectural Weaknesses & Vulnerabilities Identified

**Carried over: conditions of this verdict (team decisions)**
- [ ] **C-1 (HIGH, interface):** `AnswerOutput` has no fields for `retrieval_required`, `suppression_reason`, `claims`, `version_lineage`, `clarification_questions`. **Proposal ready**: Option A (additive, defaulted fields) or Option B (harness always logs `to_json()` + CI assertion).
- [ ] **C-2 (HIGH, interface):** `Claim` has no `confidence`, `superseded_by`, `"retracted"`. Covered by the same proposal.
- [ ] **C-3 → harness adoption (MEDIUM):** Matangi's harness must call `classify()` at utterance end, honour `needs_upstream_retrieval` (now also true for mixed turns), and run `sweep_forever()`.

**Found and fixed in this update (no longer open)**
- [x] **F-3 (HIGH, grounding): the cross-encoder rejected correct claims.**
  - Scoring a one-sentence claim against a whole multi-sentence chunk gave P(entail) ≈ 0.001 for verbatim sentences, rejecting 4 of 9.
  - Fixed with sentence-window scoring; the NLI backend now scores 45/45.
- [x] **F-4 (HIGH, grounding): the lexical verifier accepted 12 of 24 adversarial pairs.**
  - Antonym-aware polarity cut this to 7.
  - The remainder (value/role swaps, extra detail) is inherent to lexical overlap. See W-10.
- [x] **F-5 (MEDIUM, state continuity): self-correction dropped still-true claims.**
  - An empty delta query superseded every affected claim, including claims that only inherited the old value from the session.
- [x] **F-6 (HIGH, hallucination): contradicting sources were both asserted.**
  - Two close-scored chunks that disagree now produce a clarification question instead of two contradictory sentences.

**New or residual weaknesses**
- [ ] **W-10 (MEDIUM, grounding): the default backend is still lexical.**
  - It keeps CI offline and fast, but lets through value/role swaps whose numbers all appear in the cited chunk ("Venue A charges INR 60,000").
  - **Production/demo should run `entailment_backend: cross_encoder`.** The CI `nli` job keeps that path green.
- [ ] **W-11 (LOW, UX/interface): a `RETRACTED` can now follow a `COMMITTED` for the same `seq`.**
  - This happens when the contradiction gate removes a sentence after verification.
  - The WS server and UI must handle it; it is documented in the edge-case write-up.
- [ ] **W-12 (LOW, classification): mixed-turn detection is lexical before decomposition.**
  - A question clause with an unseen content word triggers the upstream pass.
  - A false positive costs one extra upstream search (never a restart). A false negative still drops the new question until the decomposer's novel sub-intent flags it.
- [ ] **W-13 (LOW, evidence): calibration and G4 are measured on a small fixture set.**
  - 45 calibration pairs; 32 judged claims.
  - The 0.5 threshold sits in the middle of a range where every threshold from 0.25 to 0.95 scores the same, which is robust but not yet validated on the real corpus.
- [ ] **W-14 (LOW, cost claim): A3 shows fewer retrievals and less evidence, but not yet a 3–5× token saving.**
  - Delta vs restart: 2 vs 4 retrieval calls, 2 vs 6 evidence chunks, 0 vs 1 stale claims, lineage kept vs lost.
  - Whole-prompt size is only ~1.1× smaller on this tiny corpus, because template text dominates.
- [ ] Still open from earlier audits:
  - **W-5 / I-5:** the slot lexicon is example-shaped, and fixing it needs `docs/corpus_audit.md`, which is not in the repo.
  - **N-6:** the stray-brace parse count.
  - Additive slot phrasing.
