## 4. Architectural Weaknesses & Vulnerabilities Identified

**Contract gaps: conditions of this verdict. All are to be raised in the team channel, none fixed unilaterally.**
- [ ] **C-1 (HIGH, interface): `AnswerOutput` cannot carry the additive A §6 fields.**
  - The missing fields are `retrieval_required`, `suppression_reason`, `controller_decisions`, `claims`, `version_lineage` and `telemetry`. They are emitted in `SynthesisResult.extensions`, and `render_output_json()` merges them.
  - The G6 invariant "every version > 1 has a `version_lineage` record" therefore depends on Matangi's harness logging `extensions` or the `synthesis.answer_version` TelemetryEvent.
  - *Ask:* an additive, optional-field schema v1.1, or an agreed rule that the harness logs `to_json()`.
- [ ] **C-2 (HIGH, interface): the frozen `Claim` diverges from A §4.1 / 02 S-4.**
  - It has no `confidence` or `superseded_by`, and `status` has no `"retracted"`.
  - Mitigation: a `ClaimMeta` side structure holds confidence, superseded_by and supporting chunks. Retraction happens before admission, since unverified drafts never enter the graph, so no status value is needed.
  - Both are team decisions to confirm.
- [ ] **C-3 (HIGH, integration/latency): turn routing must happen before decomposition.**
  - On a CONSTRAINT_REFINEMENT turn, Components 2 and 3 must not run a full decompose-and-retrieve, or `full_corpus_searches: 0` holds only inside Component 4 while the system as a whole re-searches.
  - Classification currently runs inside `handle_turn`, after upstream stages.
  - *Ask:* the harness calls `engine.delta.classifier.classify(...)`, to be exposed as `SynthesisEngine.classify()`, at `utterance_end`, and skips decomposition for refinement and presentation turns.

**Latency**
- [ ] **W-1 (MEDIUM): the LLM backend is not token-streaming.**
  - Drafts arrive only after the full HTTP response, so time to first answer token after utterance end (≤ 300 ms p95) is at risk with a local 7B model.
  - The two-pass overlap is currently "verify while the next draft is consumed", not "verify while generating".
- [ ] **W-2 (LOW): a CrossEncoder lock serialises NLI scoring across sentences.**
  - This is acceptable at the ≤ 30 ms per sentence budget. Measure it once the weights are baked.

**Concurrency**
- [ ] **W-3 (MEDIUM): `ClaimGraph` is single-writer by design (one open `Revision`).**
  - Two concurrent turns in one session raise `ClaimGraphError`, so the harness or WS server must serialise turns per session.
  - Cancelling the streamer does not stop worker threads that are already running. They only update counters, so this is harmless.

**Hallucination**
- [ ] **W-4 (MEDIUM): the default entailment backend is lexical overlap, so CI can run offline.**
  - It cannot detect negation or polarity flips, e.g. "are **not** refunded", which reuses the premise's words.
  - The numeral and entity copy check catches value errors, not meaning inversions.
  - The G4 citation-support target (≥ 85%) should be measured with `entailment_backend: cross_encoder`.
- [ ] **W-5 (MEDIUM, HC-2 hygiene): domain-specific values in config.**
  - The slot lexicon and two explicit delta queries (`international travel reimbursement exception`, `post-travel booking approval requirement`) are domain-specific.
  - They are legal under HC-2 (config, not `src/`), but a reviewer could read them as tuned to the brief's examples.
  - They should be re-derived from the corpus audit (roadmap 1.1/1.2), and the generic `query_templates` preferred for held-out generalisation.
- [ ] **W-6 (LOW): the proper-noun heuristic in `synth/text.py` is regex-based, not spaCy NER.**
  - A single-word, sentence-initial name ("Pune offers …") escapes the copy check.

**State**
- [ ] **W-7 (LOW, HC-4): the session store is not built yet.**
  - There is no TTL session store (`core/session.py`, roadmap 4.1), so engine lifetime and destruction are the harness's responsibility for now.

**Delta engine**
- [ ] **W-8 (LOW): mixed turns are not split.**
  - A turn mixing a constraint with a brand-new facet ("international, and what about visas?") is classified CONSTRAINT_REFINEMENT only; turn splitting is a D3 edge case.
  - Additive phrasing ("also for Mumbai") replaces the slot instead of extending it.

**Presentation path**
- [ ] **W-9 (LOW): translation and tone requests fall back to a prose re-render.**
  - The `present_only.jinja` LLM restyle exists (`LLMGenerator.restyle`) but is not wired in.

**Found and fixed during this audit (no longer open)**
- [x] **F-1:** the delta engine only targeted *conflicting* claims.
  - If V1 held only the general rule, "the trip was international" would plan zero queries and never surface the international exception.
  - Fixed with additive (facet × new constraint) targets behind `delta.additive_targets`. They dedupe onto conflict targets, and Example 2 still issues exactly 2 queries.
- [x] **F-2:** the verifier re-attributed sentences that had cited fabricated IDs, contrary to A §4.4.
  - The default now demotes them to uncertainty (`verifier.demote_on_fabricated: true`). Re-attribution stays for entailment and copy-check failures only.

## 5. Potential Improvements & Optimization Opportunities
- [ ] **I-1 (C-1):** propose schema v1.1 with optional `retrieval_required`, `suppression_reason`, `version_lineage` and `claims` on `AnswerOutput`. The change is additive and backwards-compatible with every stub.
- [ ] **I-2 (C-3):** add `SynthesisEngine.classify(utterance, controller_decisions)` as a pre-decomposition routing hook for Matangi's harness, and make CI assert `full_corpus_searches == 0` at system level.
- [ ] **I-3 (W-1):** add SSE streaming to `OpenAICompatibleClient` with incremental JSON-lines parsing, so each claim is yielded as soon as its closing brace arrives. This gives true sentence-level provisional → committed streaming.
- [ ] **I-4 (W-4):** bake `nli-deberta-v3-small` in `make setup`, enable `cross_encoder` in the CI profile, and calibrate `entailment_threshold` on golden plus adversarial cases. Also add a cheap negation-polarity check to `ClaimVerifier`.
- [ ] **I-5 (W-5):** derive slot values, value phrases and delta query templates from `docs/corpus_audit.md`, and drop the example-shaped explicit queries once templates match them.
- [ ] **I-6 (W-7):** a `core/session.py` TTL store that owns `SynthesisEngine` lifecycles and calls `destroy()` on expiry (HC-4). A cross-session isolation test already exists at engine level.
- [ ] **I-7 (W-9):** wire `LLMGenerator.restyle` for translation and tone. This is still ≤ 1 LLM call per turn, and the `citations ⊆ prior` assertion already guards it.
- [ ] Ensure the golden replay (`slrag replay --stream tests/fixtures/golden_example.jsonl`) runs in CI once Matangi's harness lands. `tests/synth/test_engine_golden.py` is Component 4's contract-level stand-in until then.

## 6. Architectural Strengths & Alignments
- [x] The frozen contract is transcribed verbatim and **pinned by a test**: drift is now a red build, not a Day-3 surprise.
- [x] **The closed citation allowlist is enforced at four layers**, including the data structure itself. `fabricated_id_count == 0` holds on every golden scenario, including a fake LLM that emits a fabricated `Doc_77 §9`.
- [x] **G5 is reproduced structurally**:
  - retained claims are byte-identical;
  - `full_corpus_searches` is 0 by construction, because the delta path issues targeted queries only;
  - pool-first resolution answers with zero retrievals when the EvidencePool already holds the evidence.
- [x] **The presentation path cannot reach retrieval**:
  - an AST import-closure test proves it;
  - the golden test uses a retriever that raises if called;
  - `citations(new) ⊆ citations(prior)` is a hard assertion.
- [x] **HC-5 by construction:** one synthesis call at most, and a deterministic classifier, delta engine, verifier, coverage matrix and renderer.
- [x] **Uncertainty is derived, not vibes.** The coverage matrix reproduces the brief's sentence exactly: "Catering accommodation policies for Venue A could not be verified from the retrieved corpus." Ambiguous evidence yields a clarification question: "…14 days or 7 days?".
- [x] **Ports, not imports:**
  - Component 3 is reached only through `RetrieveFn` / `EvidencePoolView`, which match the stub signatures;
  - Component 1 only through `ControllerDecision`;
  - Component 5 receives frozen `TelemetryEvent` records.

  Every owner can swap their stub without touching `synth/`.
- [x] Every threshold and lexicon is ablatable from config, e.g. `delta.additive_targets`, `verifier.demote_on_fabricated` and `generator.backend`.
